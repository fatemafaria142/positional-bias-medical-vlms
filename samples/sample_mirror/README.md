# Mirrored Samples — Mirror-Flip Positional Bias Stress Test

Mirror-flipped copies of `samples/amos22_mri/` and `samples/neurite_oasis/`, generated by
`scripts/mirror_samples.py`, for an **adversarial** positional-bias test: unlike
`samples/sample_rotation/` (a proper anatomical rotation that keeps ground truth correct),
this variant flips the volumes and deliberately leaves the ground-truth position label
**uncorrected**, so it actively disagrees with the original.

## What was done

Each subject's image + label volume was flipped along its own **Left/Right axis only**
(read per-volume from its NIfTI affine, never assumed — same convention as
`scripts/common3d.py`):

- This is a true **mirror reflection** (determinant -1), not a rotation — like flipping a
  photograph horizontally, not physically turning the patient. On its own this produces an
  anatomically invalid volume (a real person's organs don't just swap sides).
- Image and label are flipped identically and exactly on the voxel grid (`numpy.flip`, no
  interpolation), so they stay pixel-perfect aligned.
- The affine is **intentionally left unchanged** — there is no valid corrective affine for a
  reflection the way there is for a rotation, so the ground truth is recomputed from the
  flipped mask using the *old* axcodes. The result: **the recomputed side label is not
  corrected for the flip and disagrees with the original manifest.**

## Verified mismatch (AMOS22 MRI, subject `amos_0544`)

| Organ | Original `gt_side_axis0` | Mirrored `gt_side_axis0` |
|---|---|---|
| Right kidney | R | **L** |
| Left kidney | L | **R** |
| Liver | R | **L** |
| Spleen | L | **R** |
| Right adrenal gland | R | **L** |
| Left adrenal gland | L | **R** |

The organ name and prompt text ("Segment the right kidney in this image.") are **unchanged**
from the original manifest — only the volume content and the recomputed ground-truth side
have moved/flipped.

## Why this is a harder bias probe than a rotation

A proper rotation (`sample_rotation/`) relocates a structure but keeps its label true — it
tests whether the model follows content instead of array position, while staying an
anatomically valid case.

This mirror variant goes further: the prompt and the (deliberately unrelabeled) ground truth
now actively **disagree** with true anatomy. If a model has learned a positional shortcut
("right kidney" → "look on the right side of the array"), this setup will actively fool it
into grabbing the wrong structure. A model that is genuinely reading image content will still
correctly locate the real structure at its new position and score well against this
(deliberately relabeled) ground truth.

## Using it

- `voxtell-amos-mirror-kaggle.ipynb` — points `AMOS_DIR` at `samples/sample_mirror/amos22_mri`
- `voxtell-oasis-mirror-kaggle.ipynb` — points `OASIS_DIR` at `samples/sample_mirror/neurite_oasis`

Run the un-mirrored notebooks (`voxtell-amos-kaggle.ipynb` / `voxtell-oasis-kaggle.ipynb`)
and these mirror notebooks, then compare Dice / centroid accuracy between the two runs to
quantify positional bias.

## Regenerating

```bash
python scripts/mirror_samples.py
```

Reads the manifests and volumes already committed under `samples/amos22_mri/` and
`samples/neurite_oasis/` — no download needed — and (re)writes everything under
`samples/sample_mirror/`.
